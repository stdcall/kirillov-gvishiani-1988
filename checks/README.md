# Математические проверки

`just check-sage` выполняет точные вычисления в установленном Sage.
`chapter_i.py` проверяет ориентацию матрицы инцидентности на цепи из двух
элементов, формулу гауссовых коэффициентов и рекурсию при n=0,…,8 в
QQ[q,t], а также p-адический контрпример при p=2,3,5,7. У исходных
ошибочных чтений сохранены опровергающие проверки. Конечный диапазон
параметров не считается доказательством общего утверждения.

`just check-lean` компилирует сохранённые доказательства и проверяет их
аксиомы. Локально используется готовый mathlib из `LEAN_MATHLIB`;
toolchain и commit должны совпадать с закреплёнными в checks/lean/.
Соответствие тексту — по `passages` в lean-proofs.json. При изменении
математики в этих местах его проверяют заново вручную.

`StableDigits` проверяет комбинаторный шаг указания 32: стабилизация
каждой цифры вместе с общей нижней границей индексов даёт одновременную
стабилизацию всех цифр ниже фиксированного порога. Проверен и пример
цифры, уходящей к всё меньшему индексу. Построение Qₚ и формула его
метрики здесь не формализованы.

Регрессионные проверки в checks/tests меняют временный документ из
реальных глав: вставка утверждения и задачи должна сдвинуть номера и
связанные указания; счётчики следующей главы и отдельного указания
должны сброситься согласно книге. Исходники книги при этом не меняются.
