# Теоремы и задачи функционального анализа

А. А. Кириллов, А. Д. Гвишиани. Второе издание, переработанное
и дополненное. Москва: Наука, 1988. ISBN 5-02-013797-9.

Теория, задачи и указания к их решению охватывают теорию множеств,
топологию, меру и интеграл, линейные пространства и операторы,
преобразование Фурье и спектральную теорию.

Сборка из исходников описана в CONTRIBUTING.md.

В книге 742 задачи, указания к 741 из них, авторская библиография
и указатели. Подтверждённые исправления перечислены в отдельном PDF.
В [релизах](https://github.com/stdcall/kirillov-gvishiani-1988/releases/latest)
доступны книга, вариант без редакционных примечаний и список исправлений.
